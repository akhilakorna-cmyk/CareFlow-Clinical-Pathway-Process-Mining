# CareFlow: Clinical Pathway Process Mining

## Project Overview
CareFlow aims to analyze healthcare activity event logs to understand patient pathways, activity sequences, and elapsed time between clinical process steps.

## Objectives
- Load and validate event data.
- Prepare and clean the dataset.
- Analyze activity sequences and case durations.
- Identify potential process bottlenecks.
- Create charts and an interactive dashboard.

## Technologies
- Python
- Pandas
- Matplotlib
- Streamlit
- Git and GitHub

## Dataset Status
The official project dataset is pending. Synthetic sample data will be used for development and testing until an approved dataset is provided.
